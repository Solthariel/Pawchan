# Файлы обновлений

После успешной публикации workflow сохраняет сюда `data-v1.json` и
`changelogs/CODE.txt`. Их нет во вложениях GitHub Release.
Не вписывайте фиктивный размер или SHA-256: они вычисляются из подписанного APK.
Настройка и ограничения описаны в docs/UPDATE_FEED.md.

## Описания изменений

Для текстов ленты, истории и GitHub Releases действует [единый стиль](../publishing/README.md#стиль-описаний-выпусков).
Редакционная правка синхронизирует существующие текстовые копии и поля `notes`,
но не меняет адреса APK, размеры, SHA-256, версии или состав выпусков.
Встроенный текст уже опубликованного APK остаётся прежним.
