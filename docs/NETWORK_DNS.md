# DNS внешних сервисов

В «Настройки → Сеть» Vocaroo и Архивач имеют независимые профили:
системный DNS, Comss, XBOX DNS, GeoHide или собственный HTTPS-адрес DoH.
По умолчанию оба профиля используют системный DNS.

Профиль Архивача применяется только к `arhivach.vc` и его поддоменам:
капче, отправке запроса на сохранение, чтению архива, загрузке архивных
вложений и соответствующим фоновым задачам. Запросы к Двачу не переводятся
на выбранный для Архивача DNS. Cookie, проверка TLS, ограничения редиректов
и существующие ограничения фоновой работы сохраняются.

Если выбранный DoH не разрешил имя, клиент пробует исходный DNS.
Следовательно, профиль не является режимом «только зашифрованный DNS».
Свой адрес должен использовать HTTPS без логина и пароля в URL.
Настройка действует при новом разрешении имени; уже открытые соединения
могут переиспользоваться до закрытия. При необходимости перезапустите приложение.

DNS не является VPN или прокси и сам по себе не гарантирует доступ при
блокировках по IP/SNI. Доступность предустановленных провайдеров зависит
от сети пользователя.

Сохранённые ключи настроек Vocaroo не меняются. Для Архивача добавлены
`app_arhivach_dns` и `app_arhivach_dns_url`; они включены в существующий
экспорт/восстановление настроек без смены формата резервной копии.

## Проверка изменения

Детерминированные тесты проверяют область действия DNS, возврат к исходному
DNS, независимость профилей, чтение прежних настроек Vocaroo и перенос обоих
профилей через резервную копию. Они не доказывают доступность провайдеров
или обход блокировки. Полный Android LOCAL CHECK и проверку на устройстве
нужно выполнить отдельно; изолированные JVM-проверки их не заменяют.
