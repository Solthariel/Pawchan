# Разрешение адресов и прокси

В приложении нет собственных профилей DNS или DNS-over-HTTPS. При прямом соединении
используется системное разрешение адресов устройства; при работе через прокси
разрешение адреса зависит от маршрута и реализации прокси. Настройки прокси для
сервисов сохраняются отдельно и продолжают применяться.

Старые записи DNS в сохранённых настройках больше не используются. Они не удаляются
из хранилища автоматически, чтобы не изменять другие пользовательские данные.
