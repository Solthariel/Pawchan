# Аудит цветовой системы M3 — исходники colors-v5 (сохранены исправления v3)

Статус: код подготовлен для проверки, НЕ полный Android/runtime/performance PASS.
Проверялись система, роли, выбор схемы, статические/динамические схемы и advanced
customizations официального раздела Material 3, затем применение в исходниках.
Это не заявление, что реализована каждая необязательная возможность сайта.

## Что уже реализовано

| Область | Реализация и границы |
| --- | --- |
| Роли | Все 48 полей используемого Compose ColorScheme заполнены. Базовые компоненты получают MaterialTheme. |
| Контраст | Проверяются пары accent/on-accent, container/on-container, поверхности/основной и вторичный текст, inverse, fixed. Это математическая проверка непрозрачных цветов, не accessibility-аудит всех экранов. |
| Светлый/тёмный | Режимы отделены от исходного цвета, есть системный режим и самостоятельный AMOLED. |
| Палитры | Сохраняются восемь вариантов, свой RGB-источник и системные цвета Android 12+. Лавандовая и Персиковая сохранены, остальные шесть пересчитаны по согласованным направлениям. |
| Генерация | Свой RGB использует HCT/MCU TonalSpot; новые пресеты — явные приглушённые тональные палитры. Галечная имеет chroma=2, не Monochrome. RGB-ползунки выбирают источник, а не подменяют алгоритм HCT. |
| Системная схема | Используются dynamicLightColorScheme/dynamicDarkColorScheme. Обновление ключа конфигурации учитывается; актуальные ресурсы Samsung требуют проверки на телефоне. |
| Семантика | Ошибки используют error/onError. Ссылки остаются синими и подчёркнутыми; цитаты зелёными, специальный красный текст красным. Имена авторов с цветом от сайта сохраняются по UI-контракту. |
| Поверхности | Используются surfaceContainer-роли. AMOLED намеренно чернит основные поверхности, оставляя приподнятые различимыми; это настройка продукта, не отдельная готовая тема M3. |
| Состояния | Material-компоненты сохраняют штатные цвета состояний. Приглушение отключённых элементов и удалённых постов не трактуется как обычный активный текст. |
| Совместимость | Цветовые настройки, backup, legacy-темы и действующая база сохранены. Пакет, подпись и зависимости сохранены. Updater в app переключён на анонимный режим без токен-раздела. |

## Исправления текущего батча

1. Предпросмотр собственного цвета больше не обнуляется при движении RGB-ползунков.
   Поток conflated: расчёт в фоне завершается, результат показывается, затем берётся
   последний ожидающий цвет. Очередь ограничена; обновления не ждут отпускания пальца.
   Неполный HEX сохраняет последнюю картинку, но блокирует Применить.
   Применить доступно только для результата, соответствующего текущему RGB и режиму.
2. У старого текста постов были фиксированные #5677C8 / #4E8A3A / #E53935.
   На surfaceContainer готовых палитр минимум по этим трём цветам был около
   3.59–3.90:1 в разных режимах, ниже 4.5:1 для обычного мелкого текста.
   Добавлены общие семантические роли PostTextColors со светлыми и тёмными оттенками.
   Они проверяются на поверхностях готовых палитр и на выборке собственных источников.
3. Цветные варианты текста готовятся вместе с UI-моделью, не строятся заново при
   прокрутке строки. Для обычного текста обе темы переиспользуют один AnnotatedString.
   Для цветного текста сохраняются два варианта. Это увеличивает подготовку/память
   цветных постов; release macrobenchmark до/после остаётся обязательным.
   Раскрытие спойлера перестраивает только выбранный пост. Копирование, ссылки,
   исходный текст, OP/DT и раскрытие спойлеров сохраняются; суффиксы и PNG-экспорт
   используют соответствующий цвет. Цвета цитат/красного в PNG берутся из тех же ролей.
4. Выбранная доска в быстрой сетке явно использует onSecondaryContainer поверх
   secondaryContainer, вместо случайно унаследованного цвета текста.
5. Белый полупрозрачный scrollbar меню иконок заменён ролью outline: его цвет
   больше не привязан к тёмному фону. Видимость на реальном экране надо проверить.

## Что НЕ объявляется реализованным или проверенным

- Встроенного выбора Standard / Medium / High Contrast для готовых и собственных
  схем нет: выбран contrast=0. Системный ресурсный контраст не равен собственной
  реализации contrast control; поведение на Android 15/Samsung здесь не проверено.
- Генератор и готовые палитры намеренно используют spec 2021. Появившиеся позднее
  изменения M3 не подменяются молча: это не обещание точной копии всех примеров
  сайта или последней Expressive-спецификации.
- Окраска отдельных карточек по изображениям, harmonization, fidelity и собственные
  варианты алгоритма не обязательны. В colors-v5 явно ограничена chroma готовых
  пресетов; harmonization/fidelity/content-based схемы не добавлялись.
- В некоторых существующих компонентах ещё используется surfaceVariant вместо
  новых surfaceContainer-ролей. Это legacy-применение, не доказательство ошибки
  контраста и не повод без визуального принятия менять все поверхности.
- Белое/чёрное на фото, видео, капче и PIN-экране не заменялось механически на акцент.
  Контраст поверх произвольного изображения, прозрачности, выделения, цвет автора
  от сайта, системные строки и все фокус/нажатые состояния требуют отдельных
  runtime/визуальных проверок. Матрица непрозрачных ролей их не покрывает.
- Нет полной Gradle Android-сборки, Android Lint/R8, штатного LOCAL CHECK,
  device-smoke или release-замера на телефоне в этой среде.
- Host-компиляция отдельных файлов с реальными Compose/Android API и UI-заглушками
  на границах не является компиляцией и исполнением всего приложения.

## Обязательная приёмка на устройстве

Сначала допустим локальный Release APK для просмотра, не публикация:

1. Собственный цвет: непрерывно двигать каждый ползунок 5–10 секунд. Картинка остаётся
   видимой и меняется во время движения, финальный цвет совпадает с применённым.
2. Ввести неполный HEX, отменить, повернуть устройство и повторить. Не должно быть
   скрытого сохранения, исчезновения карточки, применения устаревшего результата.
3. Светлый/тёмный/AMOLED: настройки, каталог, пост с синей ссылкой, зелёной цитатой,
   красным текстом, спойлером и OP/DT. Переключать режим без перезагрузки треда.
4. PNG-экспорт: те же цвета, исходный текст, скрытые спойлеры, шапка.
5. Выбранная доска и прокручиваемое меню иконок в светлой и тёмной теме.
6. Системная палитра Samsung, крупный шрифт, TalkBack, выделение, отключённые состояния.
7. Полный LOCAL CHECK → три Python-набора → полный device-smoke всех модулей →
   свежие отчёты → release macrobenchmark текста → отдельное разрешение публикации.
