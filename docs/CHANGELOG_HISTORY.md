# История изменений

Экран открывает локальную историю без ожидания сети и проверяет обновления в фоне.
Показываются все опубликованные версии, в том числе новее установленной. Отметка
«Установлена» вычисляется по versionCode APK, а не по последней записи сервера.

## Данные и отказоустойчивость

При первом запуске используются генерируемые assets из `update/publishing`.
В последующих запусках — проверенная копия `files/changelog/history-v1.json`.
Источник сети — `history-v1.json` рядом с настроенным HTTPS-манифестом обновлений.
Тело истории и ETag записываются атомарно в одном файле. Смена источника сбрасывает
применимость старого ETag. Ответ 304 не перезаписывает данные. Ошибки сети, неверная
схема, дубликаты, пустые заметки, устаревшая или неполная история не заменяют кеш.
Ограничены размер ответа и время запроса. Отмена корутины не подавляется.

Файл `update/feed/history-v1.json` формирует `publish_feed_release.py` только после
успешной публикации APK. Отсечка — код выпущенной версии; записи следующего патча
из publishing не попадут в публичную историю раньше времени. Начальный файл
в этом патче содержит только уже выпущенные версии до 0.1.18 включительно.

История не служит источником установки APK: проверки пакета, подписи, размера и
хеша в существующем механизме обновления не меняются.
