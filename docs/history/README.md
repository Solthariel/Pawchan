# Исторические снимки

Эти документы сохранены для происхождения решений и результатов, не как
действующие разрешения на публикацию, перенос тега или изменение APK.
Команды внутри относятся к прежним исходникам/среде — не запускайте их на текущем проекте.
Исторический PASS не сертифицирует сегодняшний код; исторический FAIL не описывает
автоматически состояние уже выпущенного приложения.
