# История исправления жеста окон ответов

> Исторический снимок конкретного патча/проверки, не инструкция для текущего выпуска.
> Числа PASS/FAIL относятся только к указанной в отчёте базе и среде.
> Старые команды применения/публикации не выполнять; см. [карту действующих документов](../README.md).

Предыдущий промежуточный патч добавлял сопротивление оттягиванию. В 0.1.29 он заменён прямым движением окна за пальцем, порогом по размеру окна и скорости, согласованным движением стопки и индикатором направления.

Актуальное поведение, владельцы, проверки и ограничения описаны в [историческом снимке 0.1.29](COPY_AND_PREVIEW_PATCH.md) и [актуальной карте](../features/COPIES_AND_PREVIEWS.md). Старые значения сопротивления и порогов не являются текущим контрактом.
