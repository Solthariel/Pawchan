# Завершение цветового патча: colors-v5

Статус: исходники для локальной Release-проверки, не опубликованный выпуск.
Полная Android-сборка, device-smoke и runtime/performance проверки пока не выполнены.

## Восемь палитр

Лавандовая, Васильковая, Персиковая, Коралловая, Ванильная, Мятная,
Бирюзовая, Галечная. SYSTEM и CUSTOM остаются отдельно. Режимы
SYSTEM/LIGHT/DARK/AMOLED и живой RGB-предпросмотр сохранены из v3/v4.

Оливковая и Пудровая удалены из выбора. Их enum-ключи OLIVE/ROSE оставлены
только для чтения старых настроек и backup: OLIVE переходит в AMBER (Ванильная),
ROSE — в BURGUNDY (Коралловая). Read/save и UI используют одинаковую явную замену.
Остальные палитры, customSeed, AMOLED/black override, режим и сторонние настройки
не сбрасываются. Старый backup с этими двумя допустимыми ключами остаётся читаемым;
неизвестные ключи, как прежде, отклоняются. Это миграция выбора, не удаление данных.

## Удаление прежнего доступа

В app уже отключён приватный updater и отсутствует поле токена (из v4).
При запуске PawchanApplication существующий applicationScope на IO вызывает
removeSavedUpdateAccess. Удаляются только private-update-access.bin и его
AtomicFile остатки .bak/.new, затем alias <applicationId>.private-updates.v1
из AndroidKeyStore. Секрет не читается и не расшифровывается, ключ не создаётся.
Другие файлы и ключи не затрагиваются, ключ подписи APK не меняется.

Очистка идемпотентна. Удаление alias выполняется даже при ошибке удаления файла.
Ошибка файлов/Keystore не объявляется успехом: записывается сообщение без токена
и при следующем старте выполняется новая попытка. Отмена корутины не поглощается.
Отдельного постоянного marker, который заблокировал бы повтор, нет.

Это выполняется на устройстве только после установки и запуска новой сборки.
Из sandbox состояние телефона не проверено. Локальное удаление НЕ отзывает PAT
на GitHub. Владелец отдельно удаляет нужный fine-grained token в GitHub Settings.
Нельзя удалять keystore подписи приложения или путать его с GitHub credential.

Обычный updater и проверки HTTPS/размеров/hash/package/signature/minSdk сохранены.
Без публичного feed обновления из закрытого репозитория ожидаемо недоступны.
Новый репозиторий/feed, версия и публикация автоматически не создавались.

## Приёмка

1. После обновления запустить приложение: в выборе ровно восемь пресетов + SYSTEM
   (на Android 12+) и CUSTOM; retired варианты нигде не выбираются.
2. Старые OLIVE/ROSE переходят в Ванильную/Коралловую без потери RGB/режима/AMOLED.
3. Проверить светлый, тёмный и AMOLED на основных экранах, RGB live preview и HEX.
4. Выполнить LegacyUpdateAccessCleanupRuntimeTest: зашифрованный credential,
   остатки AtomicFile и отдельный alias удаляются. На release отдельно проверить
   запуск; host-тесты не доказывают работу Android Keystore.
5. Перед отправкой в GitHub обязательны свежие LOCAL CHECK, три Python-набора,
   полный device-smoke, отчёты и отдельное разрешение владельца. Для сохранённых
   v3 text/hot-path изменений обязателен release macrobenchmark.
