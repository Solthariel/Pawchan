# История исправления жеста окон ответов

Предыдущий промежуточный патч добавлял сопротивление оттягиванию. В 0.1.29 он заменён прямым движением окна за пальцем, порогом по размеру окна и скорости, согласованным движением стопки и индикатором направления.

Актуальное поведение, владельцы, проверки и ограничения описаны в COPY_AND_PREVIEW_PATCH.md. Старые значения сопротивления и порогов не являются текущим контрактом.
