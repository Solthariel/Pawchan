# Доработки интерфейса поверх 0.1.43 — исходники для проверки

Версия не повышена, публикация не запускалась. Этот документ не является PASS.

## Согласованный контракт

- Правый бар остаётся постовым. Шкала состоит из достижимых начал постов и отдельного
  настоящего конца, если он отличается от начала последнего достижимого поста.
  Последние короткие посты больше не получают недостижимые позиции в шкале.
  Геометрия хвостового viewport измеряется и восстанавливается; карта не меняется
  по количеству видимых постов во время жеста. Пустой отступ в конце не добавляется.
- В окнах ответов убран заголовок «Ответы на №…». Акцент SemiBold на ссылке исходного
  поста сохраняется, текст и адрес ссылки не меняются. Пять живых окон остаются.
- При создании правила исходный текст также попадает в проверяемый текст.
  Копирование находится справа от выбора regex и берёт проверяемый текст, а не
  отредактированное выражение. Инструкция описывает реальный Android Pattern,
  непустое совпадение, флаги, синтаксис и примеры. Плашка копирования сохранена.
- Ошибки regex локализованы. Недопустимое выражение не выдаётся за отсутствие совпадений.
- Исполняются только EXACT_PHRASE и REGEX. ANY_PHRASE, ALL_WORDS и ORDERED больше не
  исполняются и не предлагаются как варианты. Их идентификаторы и декодирование
  записей сохранены ТОЛЬКО для восстановления пользовательского текста: старые
  записи видны с пометкой «Не применяется». Автоматической подмены смысла нет.
  Для включения пользователь выбирает один из двух режимов и явно сохраняет правило.
- Архив использует штатную панель приложения: назад, заголовок, обновление;
  компактные строки до двух строк с многоточием; навигация страниц внизу и retry.
  Неизвестные глифы в реальных названиях не вырезаются вслепую. Только пустое
  название получает запасную подпись с номером треда.
- Каталог не ждёт статистику. board_speed загружается отдельным запросом к
  /{board}/index.json с проверкой сервера (no-cache), на текущем зеркале.
  Свежий 0 допустим; отсутствие/ошибка не превращается в 0. Последнее значение
  публикуется и в список досок без запроса index.json для каждой доски сразу.
  Следующий успешный запрос общего списка заменяет прежние наблюдения, чтобы они
  не закреплялись навсегда. Результат index, пришедший уже во время общего запроса,
  сохраняет приоритет; ошибка общего запроса последнюю цифру не стирает.
- Успешное ручное обновление каталога сбрасывает позицию к 0/0 один раз. Ошибка,
  изменение возраста, поиск и обновление одной цифры скорости позицию не сбрасывают.
  Начальная загрузка не создаёт событие ручного возврата наверх.

## Не входит в этот патч

Загрузчики картинок, видео, кэши медиа, длительность и FFmpeg не менялись.
Отдельное расследование задержки первого кадра и открытия оригиналов отложено.
Новый regex-движок и гарантированная эквивалентность PCRE2 не вводились.
Сетевое время и FPS не измерены; ускорение на устройстве пока не подтверждено.

## Перед публикацией

Полный LOCAL CHECK, три Python-набора, семь device-модулей и разбор свежих XML.
Помощник запускает ровно один цикл и сохраняет отчёт, но не коммитит и не публикует.
После изменения исходников весь цикл повторяется, а не только упавший тест.

Дополнительно обязательны release-замеры до/после на одном устройстве по контракту
PERFORMANCE.md: не менее пяти повторов, одинаковые данные, кэш и частота экрана,
frameDurationCpuMs/frameOverrunMs и trace при регрессии. Debug — не performance PASS.

Проверить запись экрана: при измерении хвоста нет видимого скачка и ложного изменения
маркера чтения; медленный ход у конца меняет реальные позиции; после отпускания нет
скачка на другую шкалу. Повторить после раскрытия длинного поста, изменения размера
окна и обновления списка, с коротким и очень длинным последним постом.

Проверить возврат из треда: прежняя позиция каталога сохранена. При ручном обновлении
с задержанной статистикой список уже обновлён и стоит наверху; последующая цифра
не прокручивает его повторно. Проверить отмену повторным обновлением и 429.

Приложенные host-логи не заменяют Android Runtime, полный LOCAL CHECK или замер.
