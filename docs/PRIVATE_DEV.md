# Pawchan Dev — рабочая Release-сборка

Release называется **Pawchan Dev**, applicationId — `com.solthariel.pawchan.dev`.
Она использует R8/minification, resource shrinking и `debuggable=false`.
Debug для instrumented tests остаётся `com.solthariel.pawchan.debug` с отдельными данными.
Существующие данные, закладки, подпись и номера версий этим изменением не переносятся.

## Обновления

«О приложении» → проверить → скачать → установить через системный установщик Android.
Feed, история и APK должны быть доступны по HTTPS без авторизации.
Адрес feed остаётся в UPDATE_MANIFEST_URL. Закрытый репозиторий не может служить
анонимным источником: недоступный feed даст обычную ошибку, а не форму доступа.
Ввод/хранение GitHub credentials, приватные API и переключение доступа удалены.
Существующие проверки SHA-256, размера, пакета, версии и сертификата APK сохранены.
APK скачивается только по нажатию; установка требует системного подтверждения.

## Подпись и проверки

Первый Dev и дальнейшие обновления должны быть подписаны одним сертификатом.
Локальный APK с временным debug-ключом не заменяет подписанный CI Release.
Публикация и push требуют отдельного разрешения после полного прогона:
LOCAL CHECK → три Python-набора → device-smoke всех восьми модулей → свежие отчёты.

Старые заметки о закрытых обновлениях в changelog описывают историю, а не
поддерживаемую текущую возможность. Никакой функционал авторизации обновлений
по ним не подключается. Старые файлы данных установленного приложения этим
исходным архивом не изменяются; работа с ними больше не выполняется при старте.
