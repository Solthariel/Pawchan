# Компактное оформление Pawchan

Общий редизайн 0.1.49 отменён по результатам ручной проверки владельцем.
Каталог, тред, панели, редактор и галерея используют компоновку до общего M3-патча.
Material-компоненты, существовавшие до него, не заменяются ради самого отката.

Сохраняются горизонтальный выбор области автоскрытия и единый стиль описаний выпусков.
Проверка зеркал открывает отдельное окно; статусы и время HTTP-проверки не встраиваются
в настройки. Время HTTP-проверки — не ICMP ping и не скорость загрузки медиа.

Переключатель снова компактный визуально. Сама строка остаётся одной доступной
областью переключения не ниже 48dp. Пояснения сокращены без уменьшения шрифта
и без принудительного обрезания текста. При крупном системном шрифте перенос допустим.
Важные предупреждения об удалении, резервных копиях и PIN сохраняются.

Откат не меняет хранилище, правила фильтрации, сетевое переключение зеркал,
проигрыватель, длительности блокировки и сохранённые пользовательские настройки.
Автотесты не заменяют визуальное принятие владельцем.


## Цветовая система

Цветовой патч на базе 0.1.50 не возвращает отменённую общую компоновку.
Меняются схемы цветов, управление ими и отключается private-режим updater. Размеры, иконки, шрифты,
скругления, движение, сетевые адреса, пакет и подпись не меняются.

Режим (как в системе / светлый / тёмный / AMOLED) отделён от палитры.
Восемь готовых вариантов: лавандовая, васильковая, персиковая, коралловая,
ванильная, мятная, бирюзовая, галечная.
Галечная использует почти нейтральные тональные роли с chroma=2.
«Из обоев устройства» доступна с Android 12 через системные Compose API.
На Android 11 импортированная системная палитра отображается как лавандовая.
Новая установка использует лавандовую палитру и системный режим.

AMOLED — постоянно тёмный режим с чёрным фоном. Отдельного переключателя
чёрного фона больше нет; цветные акценты и приподнятые поверхности диалогов
остаются различимыми. При переходе на светлый, тёмный или системный режим
чёрный override снимается атомарно, выбранная палитра и свой цвет не меняются.
Предыдущий SYSTEM/DARK + pureBlack отображается как AMOLED; LIGHT + pureBlack
остаётся светлым, поскольку чёрный фон в нём и раньше не применялся.

«Свой цвет» открывает HEX RGB и три подписанных RGB-ползунка. Предпросмотр
показывает карточку, текст и кнопку в текущем режиме. Вычисление пользовательской
схемы выполняется на Dispatchers.Default: один расчёт и один последний ожидающий
запрос. Новый ввод не обнуляет готовую картинку и не отменяет каждый кадр.
Закрытие окна отменяет владельца и дальнейшую публикацию результатов.
Только «Применить» сохраняет цвет; отмена, Back и нажатие вне окна не записывают
черновик. Неполный/некорректный HEX нельзя применить. Черновик восстанавливается
при пересоздании Compose-владельца через rememberSaveable.
Список палитр прокручивается средствами общего AppAlertDialog, строки имеют
radio-семантику, названия и образцы цвета. Поиск настроек находит строку палитры.

### Генерация и зависимости

Лавандовая #6750A4 и Персиковая #B85C26 сохраняют статические пары MCU JS 0.4.0.
Остальные шесть пересчитаны: Васильковая, Коралловая,
Ванильная, Мятная, Бирюзовая, Галечная. У новых пресетов насыщенность задаётся
явно через HCT chroma: светлый seed сам по себе не гарантирует мягкий акцент.
Все роли вычисляются одной схемой spec 2021, contrast=0, phone. Пользовательский
RGB по-прежнему использует Tonal Spot, системная схема — ресурсы Android.
Имена обозначают направление, не точное совпадение каждой роли с образцом.
См. [состав и совместимость colors-v5](COLORS_V5.md).

Для новых/пользовательских схем app имеет реального потребителя новой небольшой
JVM/Multiplatform-зависимости com.materialkolor:material-color-utilities:3.0.1 —
Kotlin-порта Material Color Utilities. Выбрана явная spec 2021 и contrast=0;
все 48 ролей Compose ColorScheme заполнены, включая container и fixed.
Прямой зависимости на Material Views и сети для вычисления нет.
Лицензионные уведомления: [Material Color Utilities](licenses/MATERIAL_COLOR_UTILITIES.txt);
копия также включена в app assets/licenses/material-color-utilities.txt.
Лавандовая и Персиковая не пересчитываются новой библиотекой.

### Владельцы и совместимость

Domain хранит ThemeColors/ThemePalette без Compose/Android. Preferences сохраняет
существующие theme_palette/theme_pure_black и новый theme_custom_seed (RGB Int)
в существующем DataStore. SettingsViewModel передаёт состояние в app-owned theme
host и экран. Новый app UI-код отвечает за draft/preview; настройки пишутся только
через существующий repository. Граф project-зависимостей не меняется.
Ошибки записи показываются; CancellationException не превращается в ошибку диска.

Старые значения ThemePreference читаются для совместимости. AMOLED также
снова доступен для выбора; Tomorrow/Neutron — тёмный синий, Normie — светлый
синий, Burichan — светлый лавандовый, Hardon — тёмный персиковый, Photon —
светлый персиковый. Это ближайшие новые варианты, не копии старых палитр.
Номера версии, пакет и подпись не меняются. App использует только анонимный
updater; адрес feed остаётся настраиваемым. В interface v11 удалены оставшиеся
приватные API, ввод/хранение доступа, шифрование и фоновая очистка старого доступа.

Экспорт/импорт включает пользовательский RGB. Отсутствующие новые поля
в старых копиях совместимы; чужой seed не наследуется, когда старая копия
явно восстанавливает другую палитру. Некорректный RGB/неизвестная палитра
отклоняются до записи. Неполная копия без цветовых полей сохраняет текущие цвета.

Стандартный порядок проверки остаётся в [DEVELOPMENT](DEVELOPMENT.md#обязательный-порядок-после-каждого-патча).
Нужны Android-сборка, LOCAL CHECK, все Python suites, полный device-smoke,
визуальная проверка на телефоне (включая большие шрифты, поворот, Back, восстановление,
быстрый ввод HEX/ползунки, обои Samsung, светлый/тёмный/AMOLED) и проверка отчётов.
Host-тесты не означают Android-runtime или performance PASS.

Результаты расширенного аудита, границы поддержки и проверка семантических
цветов постов описаны в [COLOR_SYSTEM_AUDIT](COLOR_SYSTEM_AUDIT.md).
