# Восстановление редактора v5 поверх WIP12

Статус: исходники для проверки, не релиз. Проверка на Android-устройстве,
визуальная проверка и performance-замер не выполнены. Публикация не разрешена.

## Изменения

- «Готово» сначала готовит файл в фоновом dispatcher и публикует только
  успешно обработанный результат. При ошибке редактор остаётся открыт;
  исходник не подставляется. Повторное нажатие во время обработки игнорируется.
- Экспорт подключён к общей подготовке вложений. Рецепт остаётся в черновике,
  обработанные байты — только во временном кэше. Смена опций инвалидирует кэш.
- После правок изображение растеризуется, метаданные удаляются, хеш меняется.
  Формат проверяется. Соответствующие плитки показываются включёнными и
  недоступными для отключения; остальные опции сохраняются отдельно.
- Текст автоматически выбирается после добавления. Один палец перемещает,
  два изменяют размер и поворот. Предыдущую надпись можно выбрать из списка,
  изменить текст/стиль или удалить. Жест — один шаг общей истории.
- Два пальца масштабируют/перемещают канвас без изменения экспортируемого
  файла. Для выбранной надписи эти жесты меняют надпись; «Добавить новый»
  снимает выбор и возвращает масштабирование канваса.
- Отмена/повтор перенесены в верхнюю панель, сброс — в меню. Нижняя область
  инструментов имеет одинаковую высоту для вкладок, адаптируется к высоте
  окна и прокручивается при нехватке места.
- В подтверждение выхода добавлено сохранение. Сведения о файле в окне
  перекодирования расположены после параметров.
- В чистой геометрии вместо Android PointF используется неизменяемая пара
  координат. Это устраняет три падения unit-тестов WIP12 из-за JVM-заглушки
  Android-класса, не ослабляя сами проверки геометрии.

## Где остановились в Motion

Обсуждение дошло до конца Applying transitions, следующим был Shape.
Выбран Standard: спокойный характер, без сильной пружины. Разные действия
не должны использовать один и тот же переход:

- Каталог → тред и назад: направление вперёд/назад.
- Нижние разделы: плавная смена без сдвига.
- Изображения в галерее: боковое перелистывание.
- Диалоги, меню и форма: появление/исчезновение.
- Картинка из доступной миниатюры: раскрытие из миниатюры.
- Системное отключение/масштаб анимаций Android учитываются.

Референс из переписки:
https://m3.material.io/styles/motion/transitions/transition-patterns

Существующие переходы WIP12 в этом патче не переписывались. Это восстановление
договорённостей, а не утверждение, что плавность и оба исправления мелькания
проверены на телефоне.

## Проверка

Полные результаты команд сохраняются отдельно при передаче архива. Ни unit-тесты,
ни компиляция instrumented tests не заменяют их исполнение на Android.

Обязательно проверить на устройстве:

1. JPEG/PNG/WebP, портрет с EXIF, прозрачный PNG, длинный скриншот и большие файлы.
2. Обрезку после всех поворотов/отражений; штрихи, ластик, текст и замазку.
3. Переход от одного пальца к двум, отмену прерванного жеста и общую историю.
4. «Готово», ошибку обработки, отмену, повторное открытие и восстановление черновика.
5. Фактически отправляемые пиксели: скрытые области не восстанавливаются из оригинала.
6. GIF/видео не предлагают редактор неподвижных изображений.
7. Узкий экран, крупный шрифт, альбомную ориентацию и доступность всех инструментов.
8. Оба мелькания, возврат из медиапросмотра и системные анимации 0x/0.5x/1x.
9. Полные LOCAL CHECK, Python-наборы, device-smoke и обязательный performance-замер.

Редактор не заявляется точной копией Samsung: текст выбирается списком,
удаляется кнопкой панели, а не крестиком на рамке. Размер ластика и
параметры кисти рисования/замазки регулируются ползунками.
