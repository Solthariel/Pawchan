# Экран блокировки, DNS GitHub и выравнивание досок

Патч поверх опубликованной версии 0.1.26, исходный снимок
`042af6deb225e739be2143e47448b60fc992286f`.
Публикационные файлы, версия, подпись APK и видеоплеер не изменяются.

## Блокировка

- Отдельный тёмный градиент, не снимок и не размытие защищённого содержимого.
- Круглые клавиши 72 dp, заголовок, точки и зарезервированное двухстрочное
  место для состояния. Ошибка и проверка не добавляют новые строки интерфейса.
- Слева в нижнем ряду удаление, в центре 0, справа действие.
- При пустом вводе отпечаток показывается только при одновременно включённой
  и доступной биометрии. Кнопка вызывает прежний системный диалог и криптографию.
- После ввода цифр справа OK, активная только после четырёх цифр. Разблокировка
  теперь требует явного подтверждения; старый PIN-pad редактора настроек не меняется.
- Удаление всех цифр возвращает отпечаток, если он доступен. Проверка и загрузка
  блокируют действия. Ошибки, счётчик попыток, задержки и проверка PIN остаются прежними.
- Ввод не сохраняется через rememberSaveable и очищается при ON_STOP и удалении экрана.
- Экран поддерживает вертикальную прокрутку при недостатке высоты/крупном шрифте.
- Светлые значки системных панелей настраиваются только у окна блокировки;
  флаги восстанавливаются при его закрытии. Защищённое содержимое по-прежнему скрыто
  из отрисовки и accessibility. Экстренный вызов и восстановление старым PIN не добавляются.

## GitHub DNS

Настройки → Сеть → GitHub: обновления и список изменений → DNS для GitHub.
Доступны прежние провайдеры и свой HTTPS DoH. По умолчанию «Системный», чтобы
не менять сетевое поведение и DNS-провайдера без выбора пользователя.

Профиль применяется к манифесту, тексту изменений, истории изменений и загрузке APK.
Поддерживаются github.com, githubusercontent.com, githubassets.com и их поддомены.
Суффиксы проверяются с границей домена: github.com.attacker.example не подходит.
Прочие домены и DNS форума не меняются. При ошибке/пустом ответе DoH используется
системный DNS; недействительный custom URL не включает DoH. Проверка TLS,
длины, хэша и подписи обновления не отключается. Переход HTTPS → HTTP запрещён.

Сохранённый профиль задаётся при создании AppNetworkStack, до первого запроса,
и обновляется при изменении настроек. Новый выбор действует при следующем DNS lookup;
открытое keep-alive соединение может использоваться до своего закрытия.
Настройка сохраняется в DataStore и включается в существующий экспорт настроек.

### Владение ресурсами

AppNetworkViewModel владеет AppNetworkStack и его GitHub-транспортом. Чистый клиент
GitHub заимствует только dispatcher/connectionPool; он не наследует форумные cookies,
interceptors, кэш или авторизацию. DoH bootstrap использует системный DNS, без рекурсии.
История получает этот клиент явно вместо прежнего глобального historyHttpClient.
UpdateViewModel владеет отдельными HTTP-ресурсами и заимствует долгоживущий DNS selector;
закрытие панели обновлений не закрывает общий пул/dispatcher приложения.

## Третья кнопка нижней панели: Доски

Код доски и название используют общий bodyLarge; код сохраняет полужирное начертание.
Общие значения геометрии вынесены в BoardRowStyle: отступ списка 12 dp, внутренний
отступ 16 dp, колонка кода 72 dp, промежуток перед названием 16 dp. Поэтому код
начинается в 28 dp от края списка, название — в 116 dp, независимо от длины /кода/.
Это логический start, поэтому он зеркалируется в RTL. Заголовки категорий имеют
собственную колонку индикатора раскрытия и намеренно не являются строками досок.
Размеры слотов и fast scrollbar не меняются; длинный текст по-прежнему сокращается
многоточием. Проверки текста/геометрии включены в UI-тесты.

## Проверка на устройстве обязательна

Host-компиляция и JVM-тесты не заменяют APK-сборку, Android Lint, рендеринг Compose
на телефоне, реальный BiometricPrompt и реальную сеть. Нельзя считать эти проверки
пройденными до их выполнения в Android Studio/на устройстве.
