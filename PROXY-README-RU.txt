Прокси для Pawchan

В «Настройки → Сеть» можно добавлять, редактировать, включать и удалять собственные профили SOCKS5, HTTP и HTTPS с необязательной авторизацией. Укажите имя, адрес и порт, отметьте ресурсы: 2ch, 4chan, Архивач, Vocaroo и GitHub. Один профиль можно назначить нескольким ресурсам, но один ресурс не может быть назначен двум включённым профилям одновременно. Кнопка «Проверить выбранные» открывает окно со статусом и результатом для каждого ресурса. Проверку можно повторить; закрытие окна отменяет незавершённые запросы. Указанное время — время HTTP-ответа, не ICMP-пинг. Проверка не сохраняет профиль.

При вставке в поле «Адрес» строки вида `proxy.example:1080` адрес и порт автоматически разделяются. Для IPv6 используйте скобки, например `[2001:db8::1]:1080`; IPv6 без скобок остаётся в поле адреса. Порт из вставленной строки заменяет прежнее значение. Разделение не подтверждает правильность или работоспособность адреса.

HTTP и SOCKS5 не шифруют соединение между устройством и прокси: логин и пароль могут быть видны в сети. HTTPS-прокси использует TLS с проверкой сертификата и имени узла. Поддерживаются доменные имена, IPv4 и IPv6. Учётные данные шифруются ключом Android Keystore; при невозможности их прочитать маршруты блокируются до сброса. Наличие адреса не подтверждает работоспособность прокси. Встроенные публичные списки и автоподбор удалены.

Старые настройки прокси не переносятся. При обнаружении старых или повреждённых настроек ресурсы блокируются до явного сброса. Сброс или выключение профиля включает для затронутых ресурсов соединение без прокси приложения. При ошибке сохранения изменяемые маршруты остаются заблокированы; доступна повторная попытка. Уже начатые до переключения запросы могут завершаться по прежнему маршруту.

WebView проверки 2ch не использует выбранный прокси и блокируется при включённом прокси, чтобы избежать прямого соединения. Системный DNS и сетевые настройки Android остаются. Прокси не гарантирует анонимности.

Проверки на устройстве выполняются отдельно.
