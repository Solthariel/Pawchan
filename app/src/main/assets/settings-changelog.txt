Версия 0.1.44

Изменения

- Переработана правая полоса прокрутки: сохранены шаги по постам, шкала учитывает достижимый конец списка.
- Убраны лишние заголовки окон ответов, сохранено выделение ссылки на исходный пост.
- В редакторе автоскрытия исходный текст добавляется в проверку; копирование инструкции размещено рядом с выбором регулярного выражения.
- Обновлена инструкция для составления регулярных выражений, ошибки условий отображаются по-русски.
- Для исполнения оставлены точная фраза и регулярное выражение. Старые правила сохраняются для ручного перевода, но больше не применяются.
- Исправлено восстановление старых правил из резервной копии без изменения их значений и автоматического включения.
- Обновлено оформление архива: панель навигации, компактные строки и переключение страниц внизу.
- Скорость доски обновляется из board_speed отдельно от загрузки каталога.
- Успешное ручное обновление каталога возвращает список в начало; отдельное изменение скорости не прокручивает его повторно.
